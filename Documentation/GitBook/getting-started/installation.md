# Installation

Install the ESM package:

```bash
npm install @januaryai/partner-sdk
```

```ts
import { JanuaryPartnerClient } from '@januaryai/partner-sdk';
```

The package includes JavaScript, TypeScript declarations, and the generated
transport required by its public resources. Node.js 22+ is required for
server-side use and SDK tooling.

{% hint style="info" %}
The SDK is pre-release. Pin the version supplied by January and review changes
before upgrading.
{% endhint %}
